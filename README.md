# Gym Tracker

A personal web app to log gym workouts, set by set. Built from scratch while learning HTML, CSS, JavaScript, Git and GitHub.

**Live app:** [jspintoc.github.io/gym-tracker](https://jspintoc.github.io/gym-tracker/)

## Features

- Log each set separately, with its own reps and weight
- Data stays on your device (browser storage), no accounts or server
- Works in the mobile browser

## Built with

- HTML, CSS and vanilla JavaScript
- `localStorage` for data
- GitHub Pages for hosting
